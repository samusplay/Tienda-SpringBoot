
# Backend Gestion Tienda
Backend desarrollado en Spring Boot para la gestión de ventas, inventario y sucursales de una tienda de abarrotes, apoyado en una base de datos transaccional MySQL con enfoque escalable y cloud-native.

Este proyecto surge como una alternativa tecnológica asequible para pequeños comercios que no cuentan con sistemas POS costosos, permitiendo centralizar la información y facilitar el crecimiento hacia múltiples sucursales.


## Appendix

📌 Descripción del Proyecto

El sistema permite administrar de forma centralizada:

Productos y categorías

Control de inventario en tiempo real

Registro de ventas

Reportes de stock y ventas

Gestión de sucursales

La solución está pensada para escalar progresivamente, soportando el aumento de datos y operaciones sin comprometer el rendimiento, siguiendo buenas prácticas de diseño de software y bases de datos.
